# T. 7.09.2013 E. E.2013/276 K. 2013/694

Date: 2013-09-07

Official listing text: T. 7.09.2013 E. E.2013/276 K. 2013/694

Official summary: Avukatın isteği halinde incelemenin duruşmalı olarak yapılması zorunludur. Aksi halde Anayasal hak olan savunma hakkı kısıtlanmış olur. Talep halinde kovuşturmanın duruşmalı yapılması yasal olarak zorunludur. Duruşma talebine karşın, duruşma yapılmamış olması savunma hakkının kısıtlanması sonucunu doğuracağı hakkında. ( 1136 sayılı Av.Y. m. 34, 45, 134 ; TBB Meslek Kuralları 3, 4, 7 )
